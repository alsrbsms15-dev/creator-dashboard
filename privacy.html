SG Social Dashboard – Privacy Policy

Last updated: 2026-10-22

SG Social Dashboard ("the App") is an internal analytics tool operated by the Content Marketing Team of Smilegate. It is used only by Smilegate employees to monitor the performance of Smilegate's own official social media channels (YouTube and TikTok).

What data the App accesses

With the explicit authorization of the account holder, the App reads channel-level and video-level statistics of Smilegate-owned YouTube channels through the YouTube Data API and YouTube Analytics API (subscriber counts, views, watch time, likes, comments, shares, traffic sources and audience geography). The App does not read private messages, personal contact lists, or data of any third-party account.

How the data is used and stored

Statistics are collected once a day and stored as aggregated figures in a private repository used to render an internal dashboard. The data is used solely for internal marketing analysis and reporting. It is not sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Authorization can be revoked at any time at myaccount.google.com/permissions. Stored statistics can be deleted on request.
